## Scoring anchors (fixed before outputs were opened; unchanged)

The rubric source is the Issue #113 Board record of 2026-11-24. The anchors only fix how that record's 0/1/2 scale is applied.

| Criterion | 2 | 1 | 0 |
|---|---|---|---|
| Correctness | No factual error about the V2 pack or studio rules | Minor misreadings that do not change the recommendation | A wrong claim that changes a finding or the recommendation, or an unsupported rule or file |
| Quality | Located findings (doc §) with reason, correction, and at least one non-obvious cross-document defect | Located but mostly generic or duplicative | Generic "make it better" |
| Completion | All five sections plus appendix, within ~900 words (±20%) | A section missing or materially over length | Multiple sections missing or did not finish |
| Evidence trail | Every listed source matches an actual Read event, and major findings cite file and section | Partial mismatch or uncited major findings | Claims reads that did not happen |

Reads are taken from stream-json `tool_use` events, not from the arms' self-reports.

**Decision rule, copied from the Board record:**
- **ACTIVATE** only if B cites a real read that changes a finding, scores higher on correctness or evidence, does not regress quality, and has no false invocation or prohibited action.
- **NO BENEFIT SHOWN** if B reads the sources and its findings match A's.
- **REVISE** if B is better but treats DECLARED_ONLY or SOURCE PRESENT as permission, or treats the router read set as the V2 pack.
- **BLOCKED** if quota fails, the V2 pack is absent, the two knowledge files cannot be read, or a prohibited action happens.
